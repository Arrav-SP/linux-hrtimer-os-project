# final_report/

Final case-study report and everything needed to rebuild it.

| Path | Contents |
|---|---|
| `final_report.pdf` | Submission PDF (15 pages, A4) |
| `final_report.docx` | Word version, generated from the same source |
| `report.md` | Editable source |
| `build_report.py` | Builds the PDF (headless Chrome/Edge) and the DOCX (python-docx) from `report.md` |
| `presentation_summary.md` | Material for the 10-minute presentation and viva |
| `figures/` | Figures 1–6, generated by `analysis/report_analysis.py` |
| `analysis/report_analysis.py` | All statistics and figures, computed from the raw per-trial CSV files |
| `analysis/tables/` | Summary tables written by the analysis script |
| `supplementary/` | Timer-slack / SCHED_FIFO control experiment: runner, `slackexec.c`, environment record, 18 raw CSV files and logs |

Rebuild, from the repository root:

```
python final_report/analysis/report_analysis.py
python final_report/build_report.py
```

Python packages: numpy, pandas, scipy, matplotlib, markdown-it-py, beautifulsoup4, python-docx.

The original project files are unchanged except for a one-line fix to the output filename in `scripts/analyze_native.py`.
